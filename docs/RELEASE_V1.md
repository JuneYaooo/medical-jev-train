# medical-jev-4b v1.2.0 评测报告

v1.2.0 在 1,514 道外部医疗题上按默认接口答对 **1,011 题（66.78%）**，原始 Qwen3.5-4B 为 907 题（59.91%）。开启超过 52 选项的分块淘汰后为 **1,038 题（68.56%）**，比原始模型高 7.46 个百分点（95% 区间 4.89 到 9.82）。在 1,557 道留出题上为 **80.92%**，比原始模型高 5.46 个百分点（95% 区间 3.47 到 7.60）。

## 训练

- 底座：Qwen/Qwen3.5-4B；全 32 层 Linear LoRA，rank 16、alpha 32、dropout 0.05，共 32,464,896 个训练参数。
- 数据：公开训练池经 `scripts/build_clean_data.py` 删除 307 条泄漏或标签矛盾的题后抽样，实际训练 44,347 条。
- 2 epoch、5,544 步，按开发集准确率选择第 5,000 步（开发集 80.93%）。
- 硬标签交叉熵，label smoothing 0.05；学习率 1e-4，cosine，warmup 3%，batch 8 × accumulation 2；FP16、SDPA。
- 权重 SHA-256：`130a4cc0dd588d09cbfce58d694589843b182b4b72e74a5648139f8e7d6e4bc3`。

## 局限

- 外部基准开发中反复使用，发布前也分析过留出题错题，二者都不是盲测。
- 分诊 51/100，低于原始模型的 55/100，且第一轮对话很少追问。不得用于分诊。
- 任务归类多数未经人工复核，训练标签未经临床专家逐条审核。
- 训练覆盖 2–26 个候选、1,536 token。发布接口允许 52 个候选、8,192 token，但 27–52 候选的医学准确率证据有限。
- 概率未校准，ECE 约 0.14 到 0.15，不能作为风险评分。
- 评测不覆盖开放问答、真实患者前瞻试验或临床使用安全性。

## 其他领域

在 MMLU / CMMLU 的 124 个学科上，多重比较校正后没有学科显著退步，18 个学科显著提升。完整结果见[评测文档](EVALUATION.md)（模型仓库中为 GitHub 项目的 docs/EVALUATION.md）和 `results/v1.2/summary.json`。
