# medical-jev-4b 评测报告

medical-jev-4b 在 jev-healthcare-lab 的 1,514 道外部医疗题上，准确率为 **67.90%**，比原始 Qwen3.5-4B 提高 **7.99 个百分点**，尚未超过存档 JEV 1.13。

## 同题结果

| 模型 | 答对题数 | 全部 1,514 题的准确率 |
|---|---:|---:|
| 原始 Qwen3.5-4B（同一打分方式） | 907 | 59.91% |
| **medical-jev-4b（LoRA）** | **1,028** | **67.90%** |
| JEV 1.13（存档结果） | 1,073 | 70.87% |

准确率按全部 1,514 题计算，未能回答的题目也计为错误。

相对原始 4B，提升 7.99 个百分点，按来源组 bootstrap 的 95% 置信区间为 +5.45 至 +10.41 个百分点。

相对 JEV，低 2.97 个百分点，95% 置信区间为 −5.35 至 −0.60 个百分点。这些结果不能证明超过 JEV。

## 比较方法与证据

- 数据包含 26 个任务族、1,514 项医疗判断，不含另加的 64 项共享患者试验判断。
- 学生和原始 4B 使用相同推理配置、单视图、相同选项顺序和一次前向打分；没有使用多视图集成提高主表成绩。
- JEV 1.13 使用存档中的原生多题 Choice 响应，每题包取第一次 HTTP 200。两端包装方式不同，但题目材料、指令、候选、金标及 1,514 个题目 ID 已逐项匹配；存档的三个原始文件通过 manifest 哈希校验。对照不代表 JEV 当前最新版。
- 44,847 条训练输入与基准的 ID、来源组、精确题面哈希交集均为 0。这不能排除语义近重复或底座预训练暴露。
- 权重由验证集选择；外部基准用于分析模型表现和输入覆盖，不是未接触过的盲测。发布后在当时的 1,620 道留出测试题上评测一次：1,278 题正确（78.89%）。
- 置信区间按来源组进行 1,000 次配对 bootstrap，随机种子为 17。

机器可读证据：[汇总](results/v1/comparison.json)、[隔离检查](results/v1/isolation-audit.json)、[逐题判断](results/v1/per-question.jsonl)。逐题文件保留金标和三个模型的选择，不包含病例原文。

## 训练配置

- 底座：Qwen/Qwen3.5-4B；全 32 层 Linear LoRA，rank 16、alpha 32、dropout 0.05，共 32,464,896 个训练参数。
- 实际训练 44,847 条、2 epoch、5,606 个优化步骤，按验证集选择 step 5,500。
- 硬标签交叉熵，label smoothing 0.05；学习率 1e-4，cosine schedule，warmup 3%，batch 8 × accumulation 2。
- 训练使用 FP16、SDPA、max_tokens=1,536、max_options=26、pass_position_ids=false。发布推理配置为 52 个候选、8,192 token。
- 训练验证集共 2,103 条，在配置和文件中命名为 `development`。它与训练数据隔离，不参与梯度更新，用于选择检查点及监测训练；相关指标属于训练诊断，不能作为独立测试成绩。
- 权重 SHA-256：`88c64b00d23201118a9b7b4bad192aba6a5fcb5de4e65f00542529554425b4b6`。

## 数据与复现范围

训练使用来源审核基线和 R60 来源约束病例，输入文件哈希见仓库 `configs/jev/data_sources.json`。训练标签未经临床专家逐条审核；完整语料不随模型分发，复现训练需另行取得这些输入。模型仓库提供独立推理代码、配置、权重和评测证据。

模型只对给定选项打分，概率未经校准。评测不覆盖开放问答、真实患者前瞻试验或临床使用安全性。不同硬件、精度或内核可能带来数值差异；目前没有与 JEV 的实测速度对比。

## 发布包验证

独立发布包在 RTX 5090 上完成全部 1,514 题评测：1,028 题正确、100 题超出选项编码范围。六个场景案例与仓库保存的输出完全一致，52 候选边界及长输入检查通过。环境为 PyTorch 2.8.0+cu128、Transformers 5.19.0、FP16，完整基准使用 FLA / causal-conv1d 优化内核。

Hugging Face 匿名下载文件已在 RTX 5090 上验证，全部 1,514 题的预测变化为 0、最大概率差为 0。文件哈希和 GPU 推理一致性见 [hub-validation.json](results/v1/hub-validation.json)；发布配置验证见 [package-validation.json](results/v1/package-validation.json)；输入说明见 [INPUT_LIMIT_CHECK.md](INPUT_LIMIT_CHECK.md)。
