# 模型结果

以下为当前版本（LoRA v1.1.0）发布时按发布接口（超过 52 候选计错）统计的结果。混合策略成绩、参考模型对比与 1,557 题留出测试见 [评测文档](../EVALUATION.md)。外部基准已用于诊断，不是盲测。

| 权重 | 全部 1,514 题 | 可回答 1,414 题 | ECE（可回答题） | 选中步数 |
|---|---:|---:|---:|---:|
| LoRA v1.1.0 | 1,028 / 67.90% | 72.70% | 0.1199 | 5,500 |
| 原始 4B | 907 / 59.91% | 64.14% | — | — |
| JEV 1.13 存档 | 1,073 / 70.87% | 73.90% | — | — |

ECE 使用 10 个等宽置信度箱，缺少有效概率的题不进入 ECE 分母，但仍按错误计入全部准确率。概率未经校准；此处计算 ECE 不意味着完成校准。

LoRA 相对原始模型提高 7.99 个百分点，95% 分组 bootstrap 区间 [5.45, 10.41]。可回答子集上相对 JEV 的差值为 −1.20 个百分点，区间 [−3.70, 1.27]。JEV 是存档版本；接口可回答子集排除了全部 100 道 148 候选中医证型题。

## 训练与推理口径

从固定的 Qwen3.5-4B 开始，44,847 条训练样本，答案字母打分，label smoothing 0.05；全层 LoRA，rank 16、alpha 32，按开发集选中第 5,500 步。

训练上限为 26 候选 / 1,536 token。发布包评测用 FP16、52 候选 / 8,192 token、单视图；27–52 候选只验证接口，未验证医学准确率。开发集原始 2,103 题，47 题超过候选上限、55 题超长，实际评分 2,001 题。

## 封存评测

每个定稿权重只运行一次，使用 `jev eval --sealed-ledger work/sealed-ledger.json` 登记输入与权重哈希、开始时间、完成或失败状态。重复的输入/权重组合会被拒绝，失败记录也保留。所有运行共享同一个账本；普通开发评测不使用封存集。
